# Teacher Rating

A web application that lets users submit star ratings and reviews for teachers, built with PHP, Bootstrap, and jQuery.

## Tech Stack

- **PHP**
- **Bootstrap 3**
- **jQuery**
- **Font Awesome** (star icons)

## Getting Started

### Prerequisites

- PHP 7+ with a local server (e.g. XAMPP, MAMP, or `php -S`)

### Running

```bash
git clone https://github.com/Ahmeds168/TeacherRating.git
cd TeacherRating
php -S localhost:8000
```

Then open `http://localhost:8000/index.php` in your browser.
